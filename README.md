# SQL Country Data Queries

A collection of SQL practice queries using the `country` table from the MySQL World sample database.

## Topics covered

- Selecting columns from a table
- Filtering with `WHERE`, `AND`, `OR`, and `NOT`
- Matching value ranges with `BETWEEN`
- Matching lists with `IN`
- Pattern matching with `LIKE`
- Sorting results with `ORDER BY`

## Included file

- `SQL_mini_assignment_003.sql` — country data query exercises

## Requirements

Run the queries against a database that contains the MySQL World sample database and its `country` table.

## Usage

Open the SQL file in a database editor, connect to the World database, and run the queries individually.
